# 美股板块轮动监控系统 · 监控与决策说明文档

> 版本：v1.0 ｜ 更新：2026-08 ｜ 类型：研究监控工具（非投资建议）

## 1. 系统目标

实时监控美股 11 个 GICS 行业板块，按「三层框架」输出**可执行的板块交易决策信号**：

| 层级 | 回答的问题 | 输出 |
|---|---|---|
| 第一层 · 环境开关（Regime） | 现在能不能做？ | 市场状态判定 + 建议总仓位 + 风格倾向 |
| 第二层 · 板块打分（Selection） | 具体买什么？ | 11 板块综合打分、排名、信号与建议权重 |
| 第三层 · 风控纪律（Risk） | 何时退出/降仓？ | 风控规则检查清单 + 事件倒计时 |

## 2. 监控对象

以板块 ETF 为监控载体（流动性好、可交易、可回测）：

| 代码 | 板块 | 代码 | 板块 |
|---|---|---|---|
| XLK | 科技 | XLB | 材料 |
| XLF | 金融 | XLI | 工业 |
| XLE | 能源 | XLRE | 房地产 |
| XLV | 医疗保健 | XLC | 通信服务 |
| XLP | 必需消费 | SPY | 基准（标普500） |
| XLU | 公用事业 | XLY | 可选消费 |

## 3. 第一层：环境开关（决定仓位与风格）

5 个环境指标**多数投票**，每周至少复盘一次（本系统每 5 分钟自动刷新）。

| 指标 | 数据源 | 阈值 / 信号 | 投票 |
|---|---|---|---|
| 10Y 实际利率（TIPS）水平与 3M 变动 | CNBC US10YTIPS（主）/ FRED DFII10（备） | 3M 变动 > +30bp 或水平 > 2.5% → 偏价值；3M 变动 < −30bp 或水平 < 1.8% → 偏成长 | −1 / +1 |
| 2s10s 收益率利差 | CNBC US10Y/US2Y（主）/ FRED（备） | < −40bp → 衰退预警，防御；> 0 → 走陡，进攻 | −1 / +1 |
| VIX 波动率 | CNBC VIX（主）/ Cboe 历史（备） | < 17 → 风险偏好高；17~25 → 中性；> 25 → 恐慌 | +1 / 0 / −1 |
| 高收益债利差 1M 变动 | FRED BAMLH0A0HYM2（主）/ HYG−LQD 代理（备） | 1M 扩大 > 100bp → 信用恶化；收窄 < −50bp → 改善（代理阈值 ±2%） | −1 / +1 |
| 宽松预期：2Y − EFFR | CNBC 2Y + FRED EFFR（备：2Y − 3M 代理） | 差值 < −50bp → 市场定价降息 → 偏成长 | +1 |

**总投票 → 状态与建议仓位（环境建议档位）：**

| 投票合计 | 状态 | 建议总仓位 |
|---|---|---|
| ≥ +2 | 进攻 | ~100% |
| +1 | 中性偏攻 | ~85% |
| 0 | 中性 | ~70% |
| −1 | 中性偏防 | ~55% |
| ≤ −2 | 防御 | ~40% |

> 上表为**环境建议仓位**（专家经验档位，非回测优化结果）。实际执行的**有效仓位** = 环境建议 × 风控系数（取最低），由第三层风控调制（见第 5 节）：组合回撤 >8% ×0.5 / >15% ×0、市场跌破 200 日均线 ×0.5、事件 24h 内 ×0.8、信用利差恶化 ×0.6。面板同时显示「环境建议 ~100% → 有效仓位 ~50%」及压制原因。

**环境自适应权重**：环境层不只控制仓位，还调制第二层的因子权重（防御时动量权重提高、盈利修正降低；进攻时反之），详见第 4 节。

## 4. 第二层：板块打分（决定买什么）

### 4.1 五个因子一览

| 因子 | 符号 | 权重（中性） | 一句话说明 | 数据来源 |
|---|---|---|---|---|
| 盈利修正 | rev | 35% | 分析师 EPS 预期上修/下修净比率，**领先信号**，通常领先价格 1~2 个季度 | 手动输入（默认 0；生产接 FactSet/LSEG） |
| 动量 RS | mom | 30% | 板块相对 SPY 的**相对强弱**，3 个月与 6 个月双窗口 | Nasdaq 日线自动计算 |
| 趋势 | trend | 15% | 现价相对 200 日均线的偏离，**弱趋势过滤** | 自动计算 |
| 估值 | val | 10% | PE 相对参考带的便宜程度，**只做减分项**，不做买入理由 | 手动输入 PE；缺失用静态参考带（⚠ 近似） |
| 资金流 | flow | 10% | 近期成交活跃度（量能代理，⚠），生产接 ETF 申赎数据 | 自动计算 |

### 4.2 因子计算公式

符号约定：`P` = 板块 ETF 收盘价，`SPY` = 标普 500 ETF 收盘价，`MA200` = 200 日均线，
`V5 / V60` = 5 日 / 60 日均成交量，`σ_i` = 板块 20 日年化波动率。

**① 动量 RS（mom）**

```
RS_t   = P_t / SPY_t                    # 相对强度比（对 SPY 归一）
RS3M_i = RS_t / RS_{t−63} − 1           # 63 个交易日 ≈ 3 个月
RS6M_i = RS_t / RS_{t−126} − 1          # 126 个交易日 ≈ 6 个月
因子值 M_i = 0.5 × RS3M_i + 0.5 × RS6M_i
```

> 为什么要双窗口：3 个月捕捉中短期轮动，6 个月过滤短期噪声，两者等权平均。

**② 趋势（trend）**

```
T_i = ( P_t / MA200_t − 1 ) × 100%
```

> 正值 = 站上 200 日均线（越偏离越强）；负值 = 跌破均线（弱趋势，会被降级）。

**③ 资金流（flow）—— ⚠ 量能代理**

```
F_i = V5 / V60
```

> >1 = 近期放量（资金关注度上升）；<1 = 缩量。真实资金流应使用 ETF 申赎数据，当前为近似。

**④ 盈利修正（rev）—— 手动输入**

```
R_i ∈ [−1, 1]   默认 0；正 = 上修主导，负 = 下修主导
```

> 在界面「盈利修正」列直接编辑，自动持久化。录入全部 11 个板块后 z 分分布才合理（只录个别板块会极端化其影响）。

**⑤ 估值（val）—— 手动 PE / 静态参考带**

```
V_i = clamp( (PE_hi − PE_i) / (PE_hi − PE_lo), 0, 1 ) × 100
```

> 得分越高 = 越便宜（PE 越低）。`PE_hi / PE_lo` 为各板块静态参考带（server.py 中 PE_BANDS）。
> PE 未录入时因子停用，权重摊回其余因子（见 4.5）。

### 4.3 横截面 z 分标准化

每个因子在 **11 个板块之间** 做标准化（消除板块间量纲差异，只看相对位置）：

```
z_i = (X_i − μ_X) / σ_X        # μ_X、σ_X = 该因子在 11 个板块的均值与标准差
```

- 缺失值 → `z = 0`（中性，不奖不罚）；
- 有效样本 < 2 或 σ = 0（所有板块值相同）→ 全部 z = 0（该因子本周期不产生区分度，例如只录了 1 个板块的 PE）。

### 4.4 最终得分公式

```
Score_i = w_rev·z_rev,i + w_mom·z_mom,i + w_trend·z_trend,i + w_val·z_val,i + w_flow·z_flow,i
```

- 权重 `w` 由**环境状态**决定（见 4.5），且始终满足 `Σw = 1`；
- 估值因子停用时：`w_val = 0`，其余权重按比例放大重新归一化；
- 得分越高排名越前（横截面相对比较，分数本身绝对值无意义）。

### 4.5 环境自适应权重

| 环境 | rev | mom | trend | val | flow |
|---|---|---|---|---|---|
| 进攻（投票 ≥ +1） | 45% | 25% | 15% | 5% | 10% |
| 中性 | 35% | 30% | 15% | 10% | 10% |
| 防御（投票 ≤ −1） | 20% | 45% | 20% | 10% | 5% |

> 逻辑：进攻时盈利修正（基本面领先）权重最高；防御时动量/趋势（防守质量）权重最高；估值永远只占小权重（防价值陷阱）。

### 4.6 信号与建议权重

| 排名 | 信号 |
|---|---|
| 1~3 | 买入候选 |
| 4~5 | 关注 |
| 6~8 | 观望 |
| 9~11 | 回避 |

- **趋势降级**：收盘跌破 200 日均线的板块，信号最多降至「观望」（防止接飞刀）；
- **建议权重（前 3 名，风险平价）**：

```
w_i = (1/σ_i) / Σ_{j∈top3}(1/σ_j)      # σ = 20 日年化波动率
```

> 波动率越低的板块分到越高权重（当前 XLF 波动 10.2% 最低 → 权重 50%+），组合风险更均衡。

### 4.7 实时计算示例（2026-08-14，进攻环境：rev45 / mom25 / trend15 / val5 / flow10）

以 **XLK 科技**（总分 +1.94，第 1 名）为例：

| 步骤 | 数值 |
|---|---|
| 原始因子值 | RS3M=+2.01%，RS6M=+19.78% → M=+10.90%；现价 190.01 / MA200 157.54 → T=+20.61%；量能 0.47；盈利修正 +0.35（手动）；PE=10（手动） |
| z 分（横截面） | z_rev=+2.78，z_mom=+2.10，z_trend=+2.05，z_flow=−1.46，z_val=0（仅 1 个板块有 PE，无区分度） |
| 加权贡献 | 0.45×2.78=**+1.253**，0.25×2.10=**+0.525**，0.15×2.05=**+0.307**，0.05×0=**0**，0.10×(−1.46)=**−0.146** |
| 最终得分 | **1.253 + 0.525 + 0.307 + 0 − 0.146 = +1.940** → 第 1 名「买入候选」，建议权重 16.0% |

> 同一周期 XLE 因盈利修正 −0.2（手动）贡献 −0.796，总分跌至 −0.41 → 第 9 名「回避」，可见盈利修正因子的影响力。

## 5. 第三层：风控纪律（决定何时退出）

| 规则 | 触发条件 | 动作 |
|---|---|---|
| 个股趋势熔断 | 持仓板块收盘 < 200 日均线 | 卖出该板块 |
| 排名出局 | 持仓板块总分跌出前 7 名 | 卖出该板块 |
| 组合回撤熔断 | 组合自高点回撤 > 8% / > 15% | 减半仓 / 清仓（组合高点与当前值由用户手动录入） |
| 市场回撤监控 | SPY 自 52 周高点回撤幅度 | 展示预警（> 10% 警示） |
| 事件回避 | FOMC 决议（14:00 ET）/ CPI 公布（8:30 ET）前 24h | 高贝塔板块减半 |
| 信用恶化 | HY 利差 1M 扩大 > 100bp | 全面收缩仓位 |
| 换手上限 | 单周期建议卖出信号 > 3 个 | 提示放缓，避免过度交易 |
| **有效仓位联动** | 上述风控规则同时调制第一层仓位：回撤 >8% ×0.5 / >15% ×0；市场破 200 日线 ×0.5；事件 24h 内 ×0.8；信用恶化 ×0.6 | 第一层显示「环境建议 → 有效仓位」及压制原因（取最低系数） |

## 8. 运行方式

```bash
cd us-sector-monitor
python server.py            # 默认 127.0.0.1:8077
python server.py --port 9000
python server.py --demo     # 离线演示模式（仅内置示例数据）
```

浏览器打开 `http://127.0.0.1:8077`。系统**每 5 分钟自动刷新**（可关闭），数据以美股日线为粒度，盘中亦反映最新收盘价。

## 10. 已知局限与优化路线

1. 盈利修正/资金流/估值为代理或手动数据 → 接 FactSet、ETF 申赎数据后权重可信度提升；
2. 固定阈值投票 → 可升级为滚动分位数（如 2s10s 相对 5 年分位）；
3. 离散风控阈值 → 可升级为波动率目标化（Vol Targeting）；
4. 单层打分 → 可叠加机器学习排序（XGBoost）+ 滚动样本外回测验证；
5. 数据均为日线 → 盘中高频信号需另接实时行情。
